# Netwrth app store voor Umbrel

Community app store voor [umbrelOS](https://umbrel.com) met de app [Netwrth](https://github.com/PassyP/netwrth), een self-hosted portfolio-tracker.

Installeren: App Store, dan Community App Stores, voeg `https://github.com/PassyP/netwrth-umbrel-apps` toe en installeer *Netwrth*.

Stel na de eerste start direct een wachtwoord in onder Instellingen, Beveiliging. Tot dan is de app open voor iedereen op je netwerk.
